# docs/requests/ — Cowork からの依頼を置く場所

Cowork（要件整理担当）がここに Markdown を1件1ファイルで書く。
書き込みは**ワークスペースの常駐**（`../../scripts/cowork-daemon.sh`）が検知して、
このアプリのフォルダで Claude Code をヘッドレス起動する。
**このREADME自体は監視対象から外してある**（`../../scripts/cowork-watch.sh` が除外）。

## 1ファイルの書き方

ファイル名は内容が分かるものにする。中身はこの3点が読み取れれば着手される。決まった書式は要らない。

```markdown
# 何をしたいか

## 何を変えたいか
...

## どの画面／どのデータか
...

## 既存データをどう扱うか
...
```

## 書かなくていいもの

文言・色・並び順・細かいUIの詰めは、書かなければこちらで妥当な案を採って進める。

## 止まる場合

次に当たるものは、実装せずに `../../.cowork/apps/AI議事録ツール/waiting.txt` に理由を書いて止まる。

- 何をしたいのかが読み取れない
- 外部サービス（Azure・Netlifyの環境変数設定など）の人の手が要る手続きが必要
- 本番データを消す／作り直す性質の変更

## いまの状況を見る

```
bash ../scripts/cowork-watch.sh --app "AI議事録ツール"
```
