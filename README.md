# AI議事録ツール

会話（Zoomなどの打ち合わせ・面接）をリアルタイムで文字起こしし、質問への回答案の提示や、
決定事項・宿題事項の記録を自動で行うアプリ。LIFE HUBとは別の新しいアプリ。

詳しい要件は `docs/requests/` を参照。

## できること

- **録音画面**（`/`）… マイクの音声をその場で文字にして流す。会話の中から
  「自分に向けられた質問＋回答案（カンペ）」と「決定事項・宿題事項」を、常に両方拾って表示する。
- **要約画面**（`/sessions/:id`）… 終了すると、文字起こし全文から議事録風のまとめ
  （要点・決定事項・宿題事項）を自動で作る。作り直しもできる。
- **過去のセッション一覧**（`/sessions`）… 保存したセッションを見返す。

保存先はこの端末の IndexedDB（Dexie）だけ。他端末との同期は今回の対象外。

## 音声認識について（2段階で進める）

音声認識は `src/lib/speech/` で差し替えられるようにしてある。

- **1段階目（いま）** … ブラウザ標準の音声認識（Web Speech API）。Chrome / Edge / Safari で動く。
  Firefox など非対応のブラウザ、https でない場所では、その旨を画面に出して開始できないようにしている。
- **2段階目（あとで）** … Azure AI Speech のキーが用意でき次第、`src/lib/speech/` に
  プロバイダを1つ足して `getSpeechProvider()` の選び方を変える。
  質問検知・回答案生成・要約生成・保存・画面には手を入れなくて済む形にしてある。

## 話者を分けて聞く（Deepgram / Azure を設定したとき）

音声認識のキーがサーバー側に設定されていると、そちらに切り替わり、
**音源を2本、別々に聞き取る**。Deepgram を優先し、無ければ Azure、
どちらも無ければブラウザ標準に落ちる。

| 話者 | 拾う音 |
|---|---|
| 自分 | マイク |
| 相手 | 通話の音（Zoom などの出力を仮想オーディオで受けた入力） |

これが効くと「本人が発した質問か、相手から本人への質問か」を推測しなくてよくなる。
Web Speech API は音を1本にまとめてしか聞けないため、そこを推測に頼っており、
一人で喋って試すと質問が1件も拾えない、という分かりにくい振る舞いになっていた。

どの入力デバイスをどちらに使うかは、録音画面の「どの音を、誰の声として聞くか」で選ぶ
（選択はこの端末に憶える。デバイスを抜き差ししてIDが変わったら既定に戻る）。

相手の声を拾うには、通話アプリの音を仮想オーディオ（BlackHole など）へ流す配線が要る。
macOS なら「複数出力装置」で イヤホン＋BlackHole の両方へ出し、その BlackHole を
「相手の声」に選ぶ。**複数出力装置の時計役（プライマリ装置）は実物のデバイスにすること。**
仮想デバイスを時計役にすると、Bluetooth を足した時点で音が配られなくなる。

キーが未設定のあいだはブラウザ標準の音声認識に自動で落ちるので、実装も動作確認も止まらない。

## AIのAPIキー（人の手が要る）

ブラウザから Anthropic のキーを直接使わないよう、`netlify/functions/analyze.ts` と
`netlify/functions/summarize.ts` を経由する。会話の中身はサーバーに保存しない（ログにも出さない）。

- **本番（Netlify）** … サイトの環境変数に次を設定する。**これは人（本人）が行う。**
  - `ANTHROPIC_API_KEY` … 質問検知・回答案・要約
  - `DEEPGRAM_API_KEY` … 音声認識（未設定ならブラウザ標準に落ちる）
  - `AZURE_SPEECH_KEY` / `AZURE_SPEECH_REGION` … Deepgram の代わりに Azure を使うとき
- **手元** … `.env.example` を `.env` にコピーしてキーを入れ、`npx netlify dev` で起動する。

音声認識の購読キーはブラウザに置かない。`netlify/functions/speechToken.ts` が
キーと引き換えに期限付きの合鍵を発行し、画面はそれだけを使う（切れる前に取り直す）。
ブラウザは WebSocket に独自ヘッダを付けられないため、Deepgram へはその合鍵を
副プロトコル（Sec-WebSocket-Protocol）に載せて渡している。

キーが未設定のあいだも、文字起こしと保存は動く（質問検知・要約のところだけ
「APIキーが未設定です」と出る）。

## 動作確認

```
npx tsc --noEmit   # 型チェック
npm test           # テスト（Vitest）
npm run dev        # 画面だけ（AIの関数は動かない）
npx netlify dev    # 画面＋netlify/functions
```
